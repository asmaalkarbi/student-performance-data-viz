# Data-Driven Analysis of Student Behaviors and Academic Performance

## 📌 Overview
This project analyzes how student lifestyle habits affect academic performance using data visualization and statistical analysis techniques.

The goal is to discover patterns between student behaviors and exam scores to support educational decision-making.

## 🎯 Objectives
- Analyze student lifestyle habits
- Identify factors affecting exam performance
- Build meaningful visualizations
- Provide recommendations for improving academic outcomes

## 📊 Dataset
Dataset source:
- Kaggle

Dataset details:
- 1000 student records
- 16 behavioral and academic features
- Final cleaned dataset: 956 records

Features include:
- Study hours
- Sleep hours
- Social media usage
- Internet quality
- Attendance
- Mental health
- Diet quality
- Exam scores

## 🛠️ Tools & Libraries

## 🔄 ETL Process
### Data Cleaning
- Removed unnecessary columns
- Handled outliers
- Imputed missing values
- Encoded categorical variables

### Data Transformation
- Grouping
- Filtering
- Reshaping
- Correlation analysis

## 📈 Key Findings
- Study hours have the strongest positive correlation with exam scores
- Social media and Netflix usage negatively affect performance
- Attendance and mental health strongly influence grades
- Better internet quality improves academic performance
